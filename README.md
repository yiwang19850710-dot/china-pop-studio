# China Pop Studio

这是一个离线可运行的 MVP 原型，面向非中国用户的“中国风照相馆”效果：

- 打开摄像头
- 选择夸张中国风背景模板
- 默认竖屏 9:16，适合短视频平台风格
- 新增早上好、中午好、晚上好、广场舞、公园纳凉等土味传播模板
- 模板画面使用中英文双语，中文保留土味传播感，英文帮助外国用户理解
- 摄像头人像使用柔边、暖色调和光雾融合进模板
- 调整人像窗口样式、大小和前景强度
- 模板配置集中在 `templates.js`，后续可以继续扩展成后台可编辑模板库
- 右侧控制栏新增“Template manager / 模板管理”雏形，可以直接改中英文文案、印章字和人物位置，并先保存在浏览器本地
- 拍照导出 PNG
- 录制短视频导出 WebM

## 运行方式

在这个文件夹启动本地服务后，浏览器打开：

```powershell
python -m http.server 4173
```

然后访问：

```text
http://localhost:4173
```

摄像头通常需要在 `localhost` 或 HTTPS 环境下才能正常授权。

## 打包成 EXE

建议下一步用 Electron 包装这个页面。推荐结构是：

1. 保留当前 `index.html`、`styles.css`、`app.js`
2. 保留 `templates.js` 作为模板数据入口，`admin.js` 作为轻量模板管理入口
3. 加入 Electron 的 `main.js`
4. 用 `electron-builder` 输出 Windows `.exe`

当前原型没有引入 Electron 依赖，因为这需要联网安装 npm 包。确认方向后，可以继续添加打包配置。
